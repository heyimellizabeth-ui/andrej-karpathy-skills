The toolbox

One small API. Nine ways to move.

Anime.js v4 is modular and ESM-first — import only the parts you touch. Each instrument below isolates one capability, with the exact code that drives it sitting right beside the demo.

01

Grid stagger

Drive a 13×13 field from a single timeline, rippling outward from the centre with one stagger call.

timeline · stagger(grid, from:'center')
01 · stagger
import { createTimeline, stagger } from 'animejs';

createTimeline()
  .add('.dot', {
    scale: [1, 1.6, 1],
    ease: 'inOutQuad',
    duration: 700,
  }, stagger(45, { grid: [13, 13], from: 'center' }));
02

Draw on scroll

Bind a stroke's progress directly to the scrollbar. The line draws as this block crosses the viewport.

scroll down to draw the pathstatic · fully drawn
02 · svg + scroll
import { animate, svg, onScroll } from 'animejs';

animate(svg.createDrawable('.line'), {
  draw: ['0 0', '0 1'],
  ease: 'inOut(3)',
  autoplay: onScroll({ sync: true }),
});
03

Motion path

Spread a path's coordinates into an animation and the element rides it — position and rotation handled for you.

createMotionPath · loop
03 · motion path
import { animate, svg } from 'animejs';

animate('.rider', {
  ease: 'linear',
  duration: 4200,
  loop: true,
  ...svg.createMotionPath('.track'),
});
04

Shape morph

Interpolate one SVG shape into another. Anime.js extrapolates the points so the transition stays smooth.

svg.morphTo · inOutCirc
04 · morph
import { animate, svg, utils } from 'animejs';

utils.set('.target', { points: nextShape() });
animate('.shape', {
  points: svg.morphTo('.target'),
  ease: 'inOutCirc',
  duration: 900,
});
05

Blend scatter

Function-based values give every element its own random target. composition:'blend' layers transforms without overwriting each other.

composition: 'blend' · utils.random
05 · blend
import { animate, utils } from 'animejs';

animate('.chip', {
  x: () => utils.random(-120, 120),
  y: () => utils.random(-90, 90),
  rotate: () => utils.random(-180, 180),
  composition: 'blend',
  duration: () => utils.random(500, 1000),
});
06

Draggable + spring

Throw it. On release a spring eases the puck to rest with real physics — drag, flick, snap.

drag
spring · stiffness 120 / damping 6
06 · draggable
import { createDraggable, spring } from 'animejs';

createDraggable('.puck', {
  container: '.pad',
  releaseEase: spring({ stiffness: 120, damping: 6 }),
});
07

Clockwork

Two tracks on one timeline, locked together with the '<' position — ticks pulse, the hand sweeps, forever in sync.

timeline · '<' sync · loopstatic · 12 o'clock
07 · timeline
import { createTimeline, stagger } from 'animejs';

createTimeline({ loop: true })
  .add('.tick', { opacity: [.25, 1], duration: 50 }, stagger(10))
  .add('.ticker', { rotate: 360, duration: 1920 }, '<');
08

Responsive scope

A scope re-runs your animation when a media query flips. Resize the window — the orbs swap their axis of motion.

scope · mediaQueries · orientation flipstatic
08 · scope
import { createScope, createTimeline, stagger } from 'animejs';

createScope({ mediaQueries: { portrait: '(orientation: portrait)' } })
  .add(({ matches }) => {
    const p = matches.portrait;
    createTimeline({ loop: true, alternate: true })
      .add('.orb', { x: p ? [-40,40] : 0, y: p ? 0 : [-40,40] }, stagger(120));
  });
09

Character stagger

Split a string into per-letter spans, wrap each word for a natural reveal clip, then stagger them in with a single delay call.

delay: stagger(35) · outExpo · word-wrap clip
09 · char stagger
import { animate, stagger } from 'animejs';

// split text into per-letter spans
animate('.char', {
  translateY: ['1.1em', 0],
  opacity: [0, 1],
  ease: 'outExpo',
  duration: 550,
  delay: stagger(35),
});
